# AI Startup Fundraising Setup Checklist
## Quick Reference for OpenVC + DocSend

---

## Phase 1: Pre-Launch Preparation (Week 1)

### ✅ Materials Preparation
- [ ] Finalize pitch deck (15-18 slides, PDF format, under 10MB)
- [ ] Create 1-page executive summary
- [ ] Prepare financial model (even if basic projections)
- [ ] Draft founding story / personal narrative
- [ ] Compile traction metrics and proof points
- [ ] Gather customer testimonials or case studies
- [ ] Professional headshots for team
- [ ] Product demo video (2-3 minutes, optional but recommended)

### ✅ Company Foundations
- [ ] Company website live and professional
- [ ] LinkedIn company page created and active
- [ ] Founder LinkedIn profiles optimized
- [ ] Twitter/X presence (optional but helpful for AI startups)
- [ ] GitHub repository public (if open-source component)
- [ ] Email domain set up (no Gmail for outreach)

### ✅ Legal & Financial Basics
- [ ] Company incorporated (Delaware C-corp recommended)
- [ ] Cap table clean and documented
- [ ] SAFE or note template prepared (consult lawyer)
- [ ] Data room basics ready (if you have traction):
  - Incorporation docs
  - Financial statements
  - Customer contracts or LOIs
  - Team employment agreements

## Phase 2: Platform Setup (Week 1-2)

### OpenVC Account Setup

#### Account Creation
- [ ] Go to OpenVC.app and sign up as founder
- [ ] Verify email address
- [ ] Complete personal profile
- [ ] Upload profile photo

#### Company Profile
- [ ] Enter company name and website
- [ ] Select industry: **Artificial Intelligence / AI/ML**
- [ ] Select stage: **Pre-seed** or **Angel**
- [ ] Set location: **San Francisco, CA**
- [ ] Write compelling 2-3 sentence company description
- [ ] Add funding goal amount
- [ ] Add team size and founding year

#### Onboarding Checklist
- [ ] Complete OpenVC Fundability Test (30 questions)
- [ ] Review red flags and address critical issues
- [ ] Note your fundability score for tracking
- [ ] Upload pitch deck to OpenVC
- [ ] Invite co-founders to team account (if applicable)

#### Investor Research
- [ ] Access OpenVC AI Investors list
- [ ] Access Pre-Seed Investors list
- [ ] Access Angel Investors USA list
- [ ] Build initial target list of 50+ investors

### DocSend Account Setup

#### Account Creation
- [ ] Go to DocSend.com and sign up
- [ ] Select plan: **Personal ($15/month)** to start
- [ ] Verify email address
- [ ] Complete payment setup

#### Platform Configuration
- [ ] Connect cloud storage (Dropbox/Google Drive recommended)
- [ ] Install email plugin (Gmail or Outlook)
- [ ] Configure notification preferences
- [ ] Set up mobile app for real-time alerts (optional)

#### Pitch Deck Upload
- [ ] Upload pitch deck PDF to DocSend
- [ ] Name document clearly: "CompanyName_PitchDeck_Q1_2026"
- [ ] Add document description/version notes
- [ ] Test viewing experience on desktop and mobile

## Phase 3: Investor Targeting (Week 2)

### OpenVC Investor Research

#### Filter & Search
- [ ] Apply filters:
  - **Stage:** Pre-seed, Angel
  - **Industry:** AI/ML, SaaS (if applicable)
  - **Location:** San Francisco, Bay Area, California
  - **Check size:** [Your range, e.g., $50K-$500K]

#### Build Target List
- [ ] Identify 50-100 potential investors
- [ ] For each investor, research:
  - [ ] Recent investments (last 12 months)
  - [ ] Portfolio companies similar to yours
  - [ ] Investment thesis (from website or Medium)
  - [ ] LinkedIn profile and mutual connections
  - [ ] Email address or contact method

#### Investor Prioritization
- [ ] **Tier 1 (Warm Leads):** Investors with mutual connections or strong portfolio fit (15-20 investors)
- [ ] **Tier 2 (Targeted Cold):** Investors with clear AI thesis but no connection (30-40 investors)
- [ ] **Tier 3 (General Outreach):** Investors who meet basic criteria (remaining investors)

### Create Tracking Spreadsheet
- [ ] Create Google Sheet or Airtable with columns:
  - Investor Name
  - Firm
  - Email
  - LinkedIn URL
  - OpenVC Profile URL
  - Tier (1, 2, 3)
  - Connection Type (warm intro, cold)
  - Portfolio Fit (specific companies)
  - DocSend Link (unique per investor)
  - Date Sent
  - Status (Not Sent, Sent, Viewed, Responded, Meeting, Passed)
  - Last Viewed Date
  - Time Spent on Deck
  - Notes
  - Next Action

## Phase 4: Outreach Preparation (Week 2-3)

### Email Template Creation

#### General Cold Outreach Template
- [ ] Draft cold email template (keep under 100 words)
- [ ] Personalization variables identified:
  - Investor's recent investment
  - Specific portfolio company
  - Stated thesis or blog post
  - Mutual connection or event
- [ ] Include clear ask (15-min call or meeting)
- [ ] Add DocSend link placeholder
- [ ] Test email on 3 people for feedback

#### Warm Introduction Template
- [ ] Draft intro request for mutual connections
- [ ] Draft follow-up email after intro
- [ ] Prepare your "forwardable" email (short blurb about company + ask)

#### Follow-Up Templates
- [ ] Draft follow-up #1 (3 days after send if no view)
- [ ] Draft follow-up #2 (5 days after view if no response)
- [ ] Draft follow-up #3 (1 week after view, with new update)
- [ ] Draft thank you email after meeting
- [ ] Draft "keeping warm" update email (monthly for interested investors)

### DocSend Link Creation
- [ ] Create 10 unique DocSend links for first batch of investors
- [ ] For each link, configure:
  - **Account name:** Investor name + firm
  - **Email capture:** ENABLED
  - **Password:** NOT enabled (unless proprietary tech)
  - **NDA:** NOT enabled for initial outreach
  - **Link expiration:** 60 days
  - **Downloads:** DISABLED initially
  - **Notifications:** Email on view + completion enabled

- [ ] Add each unique link to tracking spreadsheet

## Phase 5: Outreach Launch (Week 3-4)

### Week 1 of Outreach (Warm Leads)
- [ ] **Day 1:** Send to 3 Tier 1 investors (test batch)
- [ ] **Day 2:** Monitor DocSend analytics from Day 1 sends
- [ ] **Day 3:** Send to 5 more Tier 1 investors
- [ ] **Day 4-5:** Follow up with any who viewed deck (aim for 24-hour response)
- [ ] **Day 5:** Review analytics, adjust email or deck if needed

### Week 2 of Outreach (Increase Volume)
- [ ] Send to remaining Tier 1 investors (5-10 more)
- [ ] Start Tier 2 outreach (10 investors)
- [ ] Track all responses in spreadsheet
- [ ] Schedule any intro calls or meetings

### Week 3-4 of Outreach (Full Pipeline)
- [ ] Continue Tier 2 outreach (20-30 more investors)
- [ ] Begin Tier 3 outreach (10-15 investors)
- [ ] Send first round of follow-ups to non-responders
- [ ] Hold initial investor meetings
- [ ] Update pitch deck based on feedback

---

## Phase 6: Ongoing Management

### Daily Tasks
- [ ] Check DocSend analytics (10 minutes)
- [ ] Respond to any investor emails within 24 hours
- [ ] Follow up with high-engagement leads (viewed 2+ times, spent 5+ minutes)
- [ ] Update tracking spreadsheet with latest activity

### Weekly Tasks
- [ ] Send 10-15 new outreach emails
- [ ] Send 5-10 follow-up emails
- [ ] Review deck analytics for improvement opportunities
- [ ] Update traction metrics in pitch deck if significant changes
- [ ] Attend 1-2 networking events or founder meetups
- [ ] Post company updates on LinkedIn (build visibility)

### Bi-Weekly Tasks
- [ ] Request warm intros from your network (5-10 requests)
- [ ] Analyze which investors engage most (time spent, return visits)
- [ ] Adjust outreach messaging based on response rates
- [ ] Update financial model with latest actuals
- [ ] Send investor update to interested parties (even if no news, show momentum)

### Monthly Tasks
- [ ] Review overall fundraising metrics:
  - Total investors contacted
  - Email open rate (target: 60%+)
  - Deck view rate (target: 70%+)
  - Meeting conversion rate (target: 10%+)
  - Average time spent on deck
  - Drop-off patterns by slide
- [ ] Update pitch deck version if major changes
- [ ] Expand investor target list (add 20-30 new investors)
- [ ] Host office hours or demo days (if applicable)
- [ ] Reconnect with passed investors (with traction update)

## Common Pitfalls to Avoid

- ❌ **Not personalizing emails** - Generic blasts get ignored
- ❌ **Reusing DocSend links** - Ruins your analytics
- ❌ **Following up too aggressively** - Wait 3-5 days between touches
- ❌ **Ignoring high-engagement leads** - If someone views deck 3 times, CALL them
- ❌ **Stale metrics in deck** - Update traction monthly
- ❌ **Too many investors at once** - Start with 10-15, then scale
- ❌ **No tracking system** - You'll lose track of who's who
- ❌ **Giving up too early** - Fundraising is a numbers game, expect 90%+ rejections
- ❌ **Not asking for intros** - Warm intros convert 10x better than cold
- ❌ **Poor follow-through** - Respond to interested investors FAST

## Emergency Troubleshooting

### If No One is Viewing Your Deck:
- **Check:** Email open rates
- **Fix:** Improve subject line or sender reputation
- **Try:** Warmer introductions instead of cold outreach

### If View Rate is Low but Open Rate is High:
- **Check:** First 2 sentences of email
- **Fix:** Make the hook more compelling
- **Try:** Add social proof (customer names, metrics)

### If Investors View Deck but Don't Respond:
- **Check:** DocSend time spent and drop-off points
- **Fix:** Improve deck slides where investors drop off
- **Try:** More direct follow-up: "What questions can I answer?"

### If You're Getting Meetings but No Term Sheets:
- **Check:** Feedback from investor meetings
- **Fix:** Address objections (team, market, traction)
- **Try:** Pivot messaging or target different investor profile
