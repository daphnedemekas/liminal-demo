## Status Definitions

Use these standardized statuses to track progress:

| Status | Definition | Typical Actions |
|--------|------------|-----------------|
| **Not Contacted** | On target list but not reached out yet | Research, prepare personalized email |
| **Email Sent** | Initial outreach sent, awaiting response | Monitor for deck view |
| **Deck Viewed** | Opened DocSend link | Follow up within 24-48 hours |
| **Responded** | Replied to your email | Schedule call or answer questions |
| **Meeting Scheduled** | Call or meeting on calendar | Prepare for pitch meeting |
| **Meeting Held** | Initial meeting completed | Send follow-up, materials requested |
| **Interested** | Expressed interest, want to learn more | Provide additional info, data room access |
| **Due Diligence** | Actively evaluating investment | Respond to questions, provide docs |
| **Term Sheet Discussion** | Negotiating terms | Work with lawyer on terms |
| **Committed** | Verbally committed to invest | Get written commitment, close docs |
| **Closed** | Investment received! | Thank you, add to cap table |
| **Passed** | Declined to invest | Note reason, circle back in 6 months |
| **No Response** | Sent 2+ emails, no reply | Deprioritize, try again later |
| **Keeping Warm** | Interested but not ready yet | Monthly updates, stay in touch |

## Tips for Maintaining This Tracker

1. **Update immediately after interactions:** Don't let it pile up
2. **Review weekly:** Spend 30 minutes every Friday updating and planning
3. **Color-code for visual tracking:**
   - Green: Hot leads
   - Yellow: Warm leads
   - Red: Cold/no response
   - Gray: Passed
4. **Set up filters and views:**
   - View by Status
   - View by Tier
   - View by Next Action Date
5. **Export weekly:** Keep a backup of your data
6. **Share with co-founders:** If fundraising as a team, keep everyone aligned
7. **Archive closed conversations:** Move passed/closed investors to separate sheet to keep main view clean

## Google Sheets Tips

If using Google Sheets:

1. **Conditional Formatting:**
   - Highlight rows where "Follow-Up Date" is past due (red)
   - Highlight "High Interest" rows (green)
   - Highlight "Deck Viewed = Yes" but "Status = Email Sent" (yellow - needs follow-up)

2. **Data Validation:**
   - Create dropdown menus for "Status," "Tier," "Interest Level"
   - Ensures consistency in data entry

3. **Formulas to Add:**
   - `=TODAY() - [Date First Contact]` → Days since first contact
   - `=COUNTIF(Status, "Committed")` → Count of committed investors
   - `=SUMIF(Interest Level, "High")` → Count of high-interest investors
   - Auto-populate "Last Updated" with `=NOW()` when row is edited

4. **Tabs to Create:**
   - Main Pipeline
   - Meeting Notes
   - Email Templates
   - Weekly Activity Log
   - Fundraising Dashboard (summary metrics)
   - Archive (passed investors)

## Airtable Alternative

If using Airtable (more powerful for relationship tracking):

**Benefits:**
- Kanban view for pipeline stages
- Calendar view for meetings and follow-ups
- Linked records (connect investors to meetings to emails)
- Automation (auto-send follow-up reminders)
- Rich field types (attachments, ratings, etc.)

**Recommended Views:**
1. **Pipeline View:** Kanban board by Status
2. **Calendar View:** All meetings and follow-up dates
3. **Hot Leads View:** Filtered for "Interest Level = High"
4. **This Week View:** All actions due this week
5. **Archive View:** Passed investors
