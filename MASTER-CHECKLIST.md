# ✅ Master Fundraising Checklist
**Complete Setup & 8-Week Execution Plan**

---

## 🎯 Phase 1: Setup (Week 1 - Days 1-2)

### Day 1: Account Setup (2 hours)
- [ ] **Calendly Setup** (15 min)
  - [ ] Create free account at calendly.com
  - [ ] Connect Google Calendar
  - [ ] Create "Investor Meeting" event (30 min duration)
  - [ ] Set availability (weekdays 9am-5pm)
  - [ ] Copy Calendly link
  - [ ] Test in incognito mode

- [ ] **OpenVC Setup** (30 min)
  - [ ] Create account at openvc.app
  - [ ] Complete founder profile
  - [ ] Upload pitch deck (PDF)
  - [ ] Fill in company details:
    - [ ] Industry: AI/ML
    - [ ] Location: San Francisco
    - [ ] Stage: Pre-seed
    - [ ] Funding target: $______
    - [ ] One-liner pitch
  - [ ] Add team information
  - [ ] Paste Calendly link
  - [ ] Complete onboarding checklist (100%)
  - [ ] Verify profile is publicly visible

- [ ] **DocSend Setup** (45 min)
  - [ ] Create account at docsend.com
  - [ ] Start Standard Plan trial ($45/month after)
  - [ ] Upload pitch deck PDF
  - [ ] Configure security settings:
    - [ ] Enable "Email required to view"
    - [ ] Enable email notifications
    - [ ] Disable downloading
    - [ ] Add company logo
  - [ ] Create 3 link versions:
    - [ ] Link 1: [company]-warm
    - [ ] Link 2: [company]-cold
    - [ ] Link 3: [company]-vip (with password)
  - [ ] Test all links in incognito mode
  - [ ] Verify analytics tracking works

- [ ] **Tracking System** (10 min)
  - [ ] Create Google Sheet: "Fundraising Pipeline"
  - [ ] Add columns from template
  - [ ] Add first 5 target investors
  - [ ] Pin sheet to browser for easy access

### Day 2: First Applications (30 min)
- [ ] **Accelerator Applications**
  - [ ] Apply to Alchemist Accelerator
  - [ ] Apply to Heavybit (if eligible)
  - [ ] Check Y Combinator batch dates
  - [ ] Add application deadlines to calendar

- [ ] **Investor Research**
  - [ ] Review full investor list (ai-preseed-investors-san-francisco.md)
  - [ ] Highlight 20 best-fit investors
  - [ ] Add all 20 to tracking spreadsheet
  - [ ] Identify warm intro paths for top 10

---

## 🚀 Phase 2: Warm Intro Cultivation (Week 1-2)

### Week 1 Tasks
- [ ] **Identify Connectors**
  - [ ] List 10 people who could introduce you to target investors
  - [ ] Rank by relationship strength
  - [ ] Check their LinkedIn connections to verify

- [ ] **Request Warm Intros**
  - [ ] Send 3 warm intro requests (don't send all at once)
  - [ ] Draft forwardable email for each connector
  - [ ] Follow up if no response in 5 days

- [ ] **Angel Investor Outreach**
  - [ ] Identify 5 accessible angel investors
  - [ ] Request coffee meetings (not pitches)
  - [ ] Prepare 3 thoughtful questions per meeting

- [ ] **Cold Email Preparation**
  - [ ] Research 20 micro VCs from list
  - [ ] Find correct partner email addresses
  - [ ] Draft personalized emails (use templates)
  - [ ] Schedule sends for Tue-Thu 8-10am PT

### Week 2 Tasks
- [ ] **Send Cold Emails**
  - [ ] Batch 1: 5 micro VCs (Monday)
  - [ ] Batch 2: 5 micro VCs (Wednesday)
  - [ ] Track open rates in spreadsheet
  - [ ] Follow up on Batch 1 (7 days later)

- [ ] **Monitor Engagement**
  - [ ] Check DocSend analytics daily
  - [ ] Note high-engagement viewers (5+ min)
  - [ ] Follow up within 24 hours on high engagement
  - [ ] Update tracking spreadsheet

- [ ] **Relationship Building**
  - [ ] Attend 1-2 SF AI events (check Meetup, Luma)
  - [ ] Coffee meetings with 3 angel investors
  - [ ] Connect with portfolio founders on LinkedIn

---

## 💼 Phase 3: Active Pitching (Week 3-6)

### Weekly Recurring Tasks
- [ ] **Monday Morning Review** (30 min)
  - [ ] Review weekend DocSend analytics
  - [ ] Prioritize follow-ups for the week
  - [ ] Update tracking spreadsheet
  - [ ] Plan week's outreach (who, when, how)

- [ ] **Daily Activities** (1-2 hours)
  - [ ] Check DocSend notifications
  - [ ] Respond to investor emails within 24 hours
  - [ ] Send 2-3 new cold emails
  - [ ] Request 1 warm intro
  - [ ] Update tracking sheet after each interaction

- [ ] **Friday Afternoon Analysis** (45 min)
  - [ ] Export DocSend analytics
  - [ ] Calculate weekly metrics:
    - [ ] Response rate: ____%
    - [ ] Meeting conversion: ____%
    - [ ] Avg view time: ____ min
  - [ ] Identify patterns (what's working/not working)
  - [ ] Adjust strategy for next week

### Meeting Preparation Checklist
Before each investor meeting:
- [ ] Review their portfolio companies
- [ ] Check their recent tweets/posts
- [ ] Prepare 3 custom talking points
- [ ] Test Zoom/call setup 10 min early
- [ ] Have pitch deck open
- [ ] Have demo ready (if applicable)

After each meeting:
- [ ] Send thank you email within 24 hours
- [ ] Send any requested materials immediately
- [ ] Update tracking spreadsheet with notes
- [ ] Schedule next step in calendar
- [ ] Ask for intro to other investors (if positive)

### Week 3-4 Goals
- [ ] 10 investor meetings scheduled
- [ ] 50 total investors contacted
- [ ] 5 warm intros successfully made
- [ ] 3 second meetings scheduled
- [ ] Identify 1-2 potential lead investors

### Week 5-6 Goals
- [ ] 15 more investor meetings
- [ ] 100 total investors contacted
- [ ] 5-8 active conversations
- [ ] 2-3 soft commits or strong interest signals
- [ ] Begin focusing on lead investor discussions

---

## 🤝 Phase 4: Closing (Week 7-8)

### Lead Investor Focus
- [ ] **Identify Lead Candidate**
  - [ ] Must be excited (not just interested)
  - [ ] Strong conviction in your vision
  - [ ] Moves quickly
  - [ ] Has written check size you need

- [ ] **Negotiate Terms**
  - [ ] Agree on valuation
  - [ ] Review term sheet together
  - [ ] Get lawyer to review (if needed)
  - [ ] Sign term sheet

### Fill the Round
- [ ] **Create Momentum**
  - [ ] Announce lead investor to other interested parties
  - [ ] "Round is 50% full, moving fast"
  - [ ] Set soft deadline (2-3 weeks)

- [ ] **Close Follow-On Investors**
  - [ ] Prioritize those who showed strong interest
  - [ ] Send update: "Lead committed, [X] remaining"
  - [ ] Schedule final calls
  - [ ] Get soft commits

### Legal & Closing
- [ ] **Documentation**
  - [ ] Choose structure (SAFE vs. priced round)
  - [ ] Lawyer drafts documents
  - [ ] All investors sign
  - [ ] Close via wire transfer or check

- [ ] **Post-Close**
  - [ ] Send thank you to all investors
  - [ ] Announce on LinkedIn/Twitter
  - [ ] Set up monthly investor update email
  - [ ] Focus on building product

## ⚠️ Warning Signs & Fixes

### Red Flag: <20% Response Rate
**Problem**: Targeting wrong investors or message needs work
**Fix**:
- [ ] Refine investor targeting (stage, focus, geography)
- [ ] A/B test email subject lines
- [ ] Focus on warm intros over cold emails

### Red Flag: <2 Min Avg DocSend View Time
**Problem**: Deck isn't compelling or too long
**Fix**:
- [ ] Simplify deck to 12 slides
- [ ] Lead with strongest traction
- [ ] Get advisor feedback on deck

### Red Flag: Meetings But No Follow-Ups
**Problem**: Pitch needs refinement or not right investors
**Fix**:
- [ ] Ask for explicit feedback after passes
- [ ] Practice pitch with advisors
- [ ] Ensure product-market fit is clear

### Red Flag: High Interest But No Commits
**Problem**: Investors waiting for lead or signal
**Fix**:
- [ ] Create urgency with deadline
- [ ] Find one committed investor first
- [ ] Share other investor interest (social proof)

## 💪 Motivation & Mindset

### Remember:
- **Fundraising is a numbers game**: 100 nos to get 10 yeses
- **Rejection is normal**: Even great companies get 90%+ rejection rate
- **Momentum compounds**: First investor is hardest, then it accelerates
- **Focus on learning**: Every no teaches you something

### Weekly Self-Check:
- [ ] Am I reaching out to enough investors? (20+ per week)
- [ ] Am I following up consistently?
- [ ] Am I learning from feedback?
- [ ] Am I taking care of myself? (sleep, exercise, breaks)
