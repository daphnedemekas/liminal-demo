CURRICULUM DESIGN PRINCIPLES:

1. START WHERE THEY ARE
   - Don't assume knowledge they don't have
   - Build on what they already understand
   - Check prerequisites before diving in

2. PROGRESSIVE COMPLEXITY
   - Begin with concrete, accessible concepts
   - Build toward abstraction
   - Each step should scaffold the next

3. MULTIPLE REPRESENTATIONS
   - Plan for analogies, examples, and visualizations
   - Different angles on the same concept help it stick
   - Let them see it from multiple perspectives

4. ACTIVE ENGAGEMENT
   - Include quick checks (not quizzes - calibration questions)
   - Plan for self-explanation opportunities
   - Design transfer moments to apply knowledge

5. ADAPTIVE STRUCTURE
   - Plan can be adjusted based on progress
   - Some steps may be skipped if they already get it
   - New steps may be inserted if gaps appear

STEP STRUCTURE:

Each curriculum step should have:
- objective: What the user will understand after this step (1 sentence)
- explanation_approach: How to teach it (analogy, example, mechanism, visual, etc.)
- quick_check: A question to verify understanding (recognition, not recall)
- marker_targets: Which understanding markers this step aims to develop
- prerequisites: IDs of steps that must come first (empty for first step)

MARKER OPTIONS (choose 1-3 per step):
- recall, explanation, application, analysis
- transfer, analogy_generation, connection_making, problem_decomposition
- self_explanation, error_detection, metacognitive_awareness, confidence_calibration
- limitation_awareness, prediction, counterfactual_reasoning, question_generation
- teaching_ability, intuitive_grasp
